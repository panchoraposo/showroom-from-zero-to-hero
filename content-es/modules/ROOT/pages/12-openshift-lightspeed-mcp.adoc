= 10. OpenShift Lightspeed y MCP Gateway

**OpenShift Lightspeed (OLS)** es un asistente de IA integrado en la consola web de OpenShift. Combinado con el **MCP Gateway** (extensión comunitaria de Kuadrant), puede ejecutar operaciones del cluster mediante herramientas invocables por IA.

== Acceder a OpenShift Lightspeed

. Inicia sesión en la **Consola de OpenShift** en `\https://console-openshift-console.{cluster_domain}`
. Haz clic en el ícono **Lightspeed** en el header de la consola (burbuja de chat).
. Haz preguntas sobre tu cluster, workloads o conceptos de Kubernetes.

== Antes de ejecutar prompts

Dos tips para que se vea mejor y sea más entendible:

- **Tool output vs chat**: cuando una tool se ejecuta, el resultado detallado aparece en **Tool output**. El mensaje del asistente puede ser corto a propósito.
- **Modelo 3D**: usa el ícono Tech Day (abajo a la derecha) para abrir la vista 3D e identificar servidores/tools del grafo MCP.

== Walkthrough de prompts del workshop (usando tools MCP)

Ejecuta los siguientes prompts en el chat de Lightspeed. Cuando Lightspeed pida ejecutar una herramienta/acción, apruébala.

. Listar pods del stack pre-desplegado:
* `List all pods in the neuralbank-stack namespace`
. Listar Applications de Argo CD:
* `List all ArgoCD applications`
. Escalar el frontend en tu namespace generado:
* `Scale the frontend deployment to 2 replicas in the {user_name}-neuralbank namespace`
. Crear un HPA para el backend (parámetros explícitos ayudan a la tool):
* `Create a HorizontalPodAutoscaler for deployment neuralbank-backend in the {user_name}-neuralbank namespace with min 1 max 3 cpu 70`
. Desplegar Redis en tu namespace generado (elige uno):
* `Deploy a Redis database in the {user_name}-neuralbank namespace`
* `Install Redis using Helm in the {user_name}-neuralbank namespace`

. Integración con Developer Hub (tools directas, sin prefijo del gateway):
* `List all Software Templates available in Developer Hub`
* `Show me all registered components`
* `Register a new entity from https://gitea-gitea.{cluster_domain}/ws-{user_name}/ols-import-demo/raw/branch/main/template.yaml`

== Instalación (GitOps del workshop)

El workshop instala la **configuración del MCP Gateway** vía GitOps (Gateway API `Gateway` + `MCPGatewayExtension` + registros/rutas de servidores).

Si despliegas en un **cluster limpio** y quieres que GitOps también instale el **MCP Gateway Operator** (OLM / OperatorHub), habilita:

[source,yaml]
----
connectivityLink:
  mcpGateway:
    operatorInstallEnabled: true
----

Si tu cluster ya tiene **Kuadrant/Authorino** corriendo y gestionando recursos `AuthConfig`, mantenlo deshabilitado para evitar conflictos de dependencias OLM.

== ¿Qué es MCP (Model Context Protocol)?

MCP es un estándar abierto que permite a modelos de IA interactuar con herramientas externas de forma segura:

* **Tools** — Funciones que la IA puede invocar (p. ej. listar pods, sync de ArgoCD)
* **Resources** — Datos que la IA puede leer (p. ej. estado del cluster, entidades del catálogo)
* **Prompts** — Plantillas de conversación predefinidas
* **Transports** — Streamable HTTP (Kuadrant Gateway) o SSE (Developer Hub directo)

El MCP Gateway actúa como una capa de federación, agregando múltiples servidores MCP detrás de un único endpoint con autenticación unificada vía Kuadrant.

== Configuración de OLS

OpenShift Lightspeed se conecta a servidores MCP a través del custom resource `OLSConfig`:

[source,yaml,subs="attributes+"]
----
apiVersion: ols.openshift.io/v1alpha1
kind: OLSConfig
metadata:
  name: cluster
spec:
  featureGates:
    - MCPServer
  mcpServers:
    - name: mcp-gateway
      url: "http://mcp-gateway-istio.mcp-system.svc:8080/mcp"
      timeout: 120
    - name: rhdh-catalog
      url: "http://backstage-developer-hub.developer-hub.svc.cluster.local/api/mcp-actions/v1"
      timeout: 120
      headers:
        - name: Authorization
          valueFrom:
            type: secret
            secretRef:
              name: rhdh-mcp-token
----

== Registro en MCP Gateway

Cada servidor MCP backend se registra en el Kuadrant MCP Gateway:

[source,yaml]
----
apiVersion: mcp.kuadrant.io/v1alpha1
kind: MCPServerRegistration
metadata:
  name: argocd-mcp-server
  namespace: mcp-system
spec:
  targetRef:
    name: argocd-mcp-server-route
  toolPrefix: argo
  path: /mcp
----

El `toolPrefix` asegura que los nombres de tools no colisionen entre servidores (p. ej. `argolist_applications` vs `k8spods_list`).

== Servidor MCP de ArgoCD

El servidor MCP de ArgoCD (`argoproj-labs/mcp-for-argocd`) corre sobre la imagen certificada `ubi9/nodejs-22` y usa transporte Streamable HTTP:

[source,yaml]
----
image: registry.redhat.io/ubi9/nodejs-22:latest
command: ["npx"]
args: ["argocd-mcp@latest", "http"]
env:
  - name: ARGOCD_BASE_URL
    value: "https://openshift-gitops-server.openshift-gitops.svc.cluster.local"
  - name: ARGOCD_API_TOKEN
    valueFrom:
      secretKeyRef:
        name: argocd-mcp-token
        key: ARGOCD_API_TOKEN
----

== Customer Service MCP

El workshop también despliega un **Customer Service MCP** como parte del stack Neuralbank. Este servidor MCP expone operaciones de backend (CRUD de clientes, credit scoring) como tools invocables por IA:

[.console-input]

----
# Check MCP server tools endpoint

  "https://{user_name}-customer-service-mcp.{cluster_domain}/tools" \
  | jq .

== Resumen

OpenShift Lightspeed junto al MCP Gateway provee **55 tools federadas** a través de 5 servidores MCP:

[cols="1,1,1",options="header"]
|===
| Server | Prefix | Tools

| k8s-mcp-server | `k8s` | 22
| ocp-mcp-server | `ocp` | 19
| argocd-mcp-server | `argo` | 14
| rhdh-mcp-server | _(none)_ | 7
| customer-svc-mcp | _(app)_ | varies
|===

Esto transforma la consola de OpenShift en un centro de operaciones con IA, donde engineers de plataforma pueden gestionar recursos Kubernetes, Applications de ArgoCD, el catálogo de Developer Hub y servicios de negocio — todo mediante lenguaje natural.
